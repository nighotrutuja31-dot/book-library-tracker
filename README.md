# 📚 Book Library Tracker

A responsive Book Library Tracker developed for VEDA Technology Internship - Task 26.

## 🎯 Objective

Build a web application to track books that are:

- Read
- Currently Reading
- Want to Read

The application also supports ratings and simple reading statistics.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Array.filter()

## ✨ Features

- Add books
- Edit books
- Delete books
- Search books
- Filter by reading status
- Rate completed books
- Reading statistics
- LocalStorage persistence
- Responsive design
- Mobile-friendly interface

## 📊 Statistics

The dashboard displays:

- Total Books
- Books Read
- Currently Reading
- Want to Read
